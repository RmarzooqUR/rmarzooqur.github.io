# Subgrid
- css subgrid allows you to work like designers that create a global grid and align nested children to this grid
- the css grid property is only available to the direct children of a parent
    - subgrid allows deep nested children to use parents grid tracks

```css
.container {
    display: grid;
    grid-template-rows: 2 1fr,1fr;
    grid-template-columns: 2 1fr, 1fr;
}

.child {
    display: grid;
    grid-template-rows: subgrid;
    grid-row: span 2 / span 2;
}
```


# Subgrid in tailwind
combination of classes
```html
<!-- The parent grid -->
<div className="grid-rows-4">
    <!-- The child which aligns its contents with the parent's grid of 4 rows -->
    <div className="grid grid-rows-subgrid">
        <!-- specify how many rows a child will span -->
        <div className="row-span-2 row-start-1"></div>
        <!-- specify which row will a child be start from -->
        <div className="row-start-3"></div>
    </div>
</div>
```
